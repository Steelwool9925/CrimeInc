# Job-resolution cues

Four short mono mp3s (each under 600 ms) live here. If one is missing the game plays that cue
silently: a missing cue is swallowed by `AudioPlayersOutcomeSfx`, never an error.

| File | Plays |
|---|---|
| `riser.mp3` | The held breath before a verdict |
| `hit-light.mp3` | A win that was a scrape |
| `hit-heavy.mp3` | A strong or major win |
| `thud.mp3` | A failure |

Only add files whose licence allows redistribution (CC0 or equivalent), and record the source
and licence below.

## Sources
All four are **generated placeholders** (2026-10-08): plain synthesized tones and noise written by a
script, mono 44.1 kHz, 96 kbps. They carry no third-party material, so there is no licence to
honour and they may be redistributed freely. Replace any of them with a designed cue of the same
filename; nothing else needs to change.

| File | Length | Synthesis |
|---|---|---|
| `riser.mp3` | 540 ms | Rising sine sweep, swelling in volume, with a fast tremolo |
| `hit-light.mp3` | 220 ms | Short bright two-tone blip with a click |
| `hit-heavy.mp3` | 480 ms | Falling low thump plus a noise burst |
| `thud.mp3` | 380 ms | Deep dropping sine with a little noise |
