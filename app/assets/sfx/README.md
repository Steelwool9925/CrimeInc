# Job-resolution cues

Four short mono mp3s (each under 600 ms) are expected here. Until they exist the game plays
silently: a missing cue is swallowed by `AudioPlayersOutcomeSfx`, never an error.

| File | Plays |
|---|---|
| `riser.mp3` | The held breath before a verdict |
| `hit-light.mp3` | A win that was a scrape |
| `hit-heavy.mp3` | A strong or major win |
| `thud.mp3` | A failure |

Only add files whose licence allows redistribution (CC0 or equivalent), and record the source
and licence below.
